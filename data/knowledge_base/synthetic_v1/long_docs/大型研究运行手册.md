# 星澜大型研究运行手册
本文属于星澜研究实验室的虚构测试语料。组织、人员、项目、日期和业务指标均为测试设定，不代表真实制度或实际项目状态。

手册版本：2026-09。全书由120个独立演练场景组成。每个场景的参数只在本场景有效，不是全项目默认配置。

## DRILL-001：霁月的召回为空演练

### 触发条件
演练编号DRILL-001，关联项目霁月。本次观测窗口为16分钟，抽样量为22条。事件由测试台自动注入，只代表本次模拟场景。运行记录应先保留原始时间戳、来源文档和查询条件，然后比较预期与实际结果。

### 调查过程
第一步检查问题中的对象是否唯一。相同产品名称可能分属于多个项目，必须联合项目编号进行判断。第二步确认索引与源文件版本对应，避免把历史片段当成当前结论。第三步比较语义检索返回的片段与其相邻内容，看是否缺少否定句、例外条件或表头。
针对召回为空，本场景要求先取2个相邻片段，再由复核人核对业务条件。一次请求成功不能证明恢复有效，至少需要比较本次样本中失败案例与成功案例的差异。诊断中只记录已观测的状态，不自行推断审批结论。

### 操作记录
观察员将每次工具调用视为一次证据获取事件，记录调用目标、返回范围和是否截断。路径来自实际文件工具或检索元数据；如果文件未读取，不给文件正文编造结论。超出工具预算时保留已有证据并说明缺口，不通过重复提交相同范围绕过限制。
本场景的故障标识为SIG-317，该标识与其他演练不能互换。事件回放时先按时间升序排列，再查看配置发布、索引更新和模型调用之间的先后关系。若只有现象相同而证据不同，需要建立独立事件记录。

### 验收与恢复
恢复判定需要满足：测试输入可复现、返回范围可解释、引用能定位原文、无答案问题未被强行补齐。运行正常与事实正确分别记录，不能使用延迟降低来替代引用正确率检查。重试上限为2次；超过后将事件交给人工复核。
